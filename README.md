# Homebrew tap

Homebrew casks for [Afterhours](https://github.com/PunGrumpy/afterhours), a menu bar app that keeps your Mac awake while coding agents work.

```bash
brew install --cask pungrumpy/tap/afterhours
```

A workflow checks for a new Afterhours release every hour and updates `Casks/afterhours.rb` on its own.
