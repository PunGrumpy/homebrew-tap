# Homebrew tap

Homebrew casks for two menu bar apps.

| App | What it does | Install |
| --- | --- | --- |
| [Afterhours](https://github.com/PunGrumpy/afterhours) | Keeps your Mac awake while coding agents work. | `brew install --cask pungrumpy/tap/afterhours` |
| [Peony](https://github.com/PunGrumpy/peony) | Switches between your VPNs and keeps only one on. | `brew install --cask pungrumpy/tap/peony` |

A workflow checks each app for a new release every hour and updates its cask on its own.
